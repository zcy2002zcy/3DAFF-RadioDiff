# AFF 主实验 + 原版配置 Transformer（v3）

本版本在现有 10 轮粗预测 + 10 轮残差扩散主实验上增加 Transformer。
它不是恢复早期含 RSS 采样的整套训练方法，也不是对旧检查点继续训练。
本目录是可独立运行的新版本入口；D 盘原代码、数据、检查点和结果保持不变。

## 已确定的结构

粗预测器和残差扩散器分别使用：

`3D 编码器 → 3D 残差块 → 2 层空间 Transformer → 3D 残差块 → 3D 解码器`

两阶段各自拥有独立的 Transformer 参数。每个阶段在四个高度之间共享其
Transformer 权重，但分别处理每个高度平面的空间 token；不把四个高度展成
一条全局 token 序列。跨高度信息仍由现有 3D 卷积处理。

| 项目 | 原版 Transformer | 本版本 |
| --- | --- | --- |
| 隐藏维度 | 128 | 128 |
| 注意力头数 | 4 | 4 |
| Transformer 层数 | 2 | 2 |
| FFN 中间维度 | 256 | 256 |
| 激活 | GELU | GELU |
| Dropout | 0 | 0 |
| 归一化与残差 | pre-LN + 两条残差连接 | 相同 |
| 位置编码 | 无 | 无 |
| 注意力范围 | 单高度平面的全部空间位置 | 相同 |

原配置依据为 D 盘项目的 `configs/base_pl_aff_random10_fullnoise.yaml`，
模块依据为 `models/transformer.py`，插入位置依据为 `models/radiodiff.py`。
“配置一致”指上面的 Transformer 配置，不是把旧版 CNN、RSS 输入或扩散调度一并搬回。
当前主干的 base_channels 仍为 32，经过两次编码后瓶颈正好为 128，无需增加投影层。

注意力不返回未使用的权重矩阵（`need_weights=False`），以减少额外显存占用。
这保留原注意力方程和可训练参数，但不同计算内核不保证逐位相同。
该设置也不保证所有后端都完全避免内部注意力矩阵，峰值显存以实际 GPU 预检为准。
训练时可重算注意力激活以节省内存；不缩小空间、改为局部窗口或减少注意力头数。

## 不变的实验口径

- 无 RSS 采样预测：sample_rate=0，不使用 IDW，不把 GT 或评分掩码送入推理网络。
- 建筑/发射机输入和 LoS、遮挡深度派生方式不变，AFF 仍为当前的逐体素 3D 融合。
- 联合预测 1、2、3、4 米四高度，原始 256 × 256 空间分辨率不变。
- 原场景互斥 train/val/test 数据划分，全部 108200 个训练样本；固定 seed42。
- 10 轮粗预测 + 10 轮残差扩散，batch2、AdamW、lr=1e-4、weight_decay=1e-4、EMA=.999。
- 当前 cosine 200 时刻、v 参数化、残差 scale=.5、几何投影和高噪声损失不变。
- 验证集 32 样本选择检查点；扩散检查点仍按固定 DDIM30、strength1 验证。
- 仅在验证集选择推理步数/强度，再冻结后测试；不根据测试指标改参数。
- 正式测试为原 200 个样本、四高度、3 次推理噪声重复；评分定义、有效区域和 PSNR range2 不变。

原 v2 的固定 DDIM200 结果属于独立评估，不是本版本已有结果。
原来的多模型 DDIM200 脚本不能直接套用本版本检查点；不得把旧 v2 的 200 步结果
标为新 Transformer 结果。本次不自动启动任何训练、GPU 预检或评估。

## 隔离与使用

Python 环境：`D:\Anaconda3\envs\rmdm5070\python.exe`。

不能把旧 v2、消融或基线输出目录作为本版本输出，也不能把旧检查点作为本版本的
resume 起点。本版本 checkpoint、protocol 和源文件摘要单独校验。
本版本完成训练后，也不能用旧模型类加载并声称包含 Transformer。

测试位于 `tests/`：使用 CPU 合成小空间张量，保留完整的 128 维、4 头、2 层配置。
它们不是正式训练、真实测试集评估或 GPU 显存可用性保证。
2026-10-28 验证：24 项 CPU 测试全部通过，包括原版前向/梯度对照、两阶段合成
单步训练及 checkpoint/EMA 保存加载回环、禁用通道隔离、旧版本拒绝和跨进程锁。
默认 PowerShell 入口的只读检查也已通过；正式新输出目录尚未创建。
正式 256 × 256、batch2 的 GPU 前向/反向显存和速度预检尚需在获准使用 GPU 时进行；
若资源不足，应报告，不自动缩模型或更改 batch。

## 如何解释后续结果

- 新增 Transformer 后需要从头训练新版本；旧结果仍属于“不含 Transformer”的 v2。
- 同为 10+10 轮不代表计算预算相同。新增注意力提高计算量，不能提前保证提升。
- 每个阶段新增 264960 个参数，共 529920 个；不是把旧网络宽度整体改成 128。
- 最直接的结构对照是原 v2 与本 v3，其他训练和评分约定固定。
- 原 v2 的测试表现已经被查看，因此本次是后续探索，不能描述为完全未见测试集的确认性实验。
- 3 次推理噪声重复不是 3 个独立训练种子，不作为训练种子误差条。
